# Receipt Splitter

Use this skill when a user provides one or more receipt images plus a natural-language instruction such as “小王请客午饭，其他人 AA”, and needs machine-readable bill data for a group ledger.

## Required behavior

1. Read the group context supplied by the caller: `group_id` and the current member list. Never invent a payer or a member outside that list.
2. Send the receipt images and a strict JSON extraction prompt to the OpenAI-compatible Qwen endpoint. Read `DASHSCOPE_API_KEY`, `QWEN_BASE_URL`, and optionally `SYNCMATE_QWEN_MODEL` from the environment. Never put credentials in source code or returned JSON.
3. Require the actual payer to be stated or supplied by the caller. A receipt payment method does not identify a group member.
4. Interpret the natural-language rule item by item, normalize all amounts to integer cents, and validate the result before returning it. “A 请客某项” means A alone bears that item's cost; it does not mean the other members bear it.
5. Compute transfers only in deterministic code from payer amounts minus member obligations. Never trust transfer amounts generated by the model.
6. If the receipt, payer, participant, rule scope, or amount is ambiguous, return a structured clarification error. Do not silently guess.
7. Meal-scoped rules (早餐/午餐/晚餐) must be matched to each receipt's visible transaction time. If the model cannot read a receipt time or the requested meal does not match, return a clarification error instead of assigning items by image order.

## Output contract

The executable helper in `scripts/receipt_splitter.py` returns:

```json
{
  "version": "1.0",
  "status": "ok",
  "bill": {
    "title": "午饭",
    "category": "餐饮",
    "bill_date": "2026-09-04",
    "currency": "CNY",
    "total_cents": 26800,
    "payers": [{"user_id": 1, "amount_cents": 26800}],
    "participants": [{"user_id": 2, "amount_cents": 13400}, {"user_id": 3, "amount_cents": 13400}],
    "split_method": "fixed",
    "ai_generated": true,
    "requires_confirmation": true
  },
  "transfers": [{"from_user_id": 2, "to_user_id": 1, "amount_cents": 13400}],
  "explanation": "小王支付并请客；其余成员平均承担",
  "raw_analysis": {}
}
```

The backend should persist this as `pending`, add an `AI分析` tag, store `raw_analysis` and the original instruction, and allow only a group owner/admin to promote it to `active`.
